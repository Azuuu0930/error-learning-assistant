# あなたにお願いする現実での調査

状態：**未実施**。この文書・記録表は準備物で、利用者の声や学習効果の実績ではありません。実施しなくても開発・基本機能の公開を止めません。

## 依頼を一括で

Python初学者の学生5〜8人に、1人約20分の協力をお願いしてください。連絡・日程調整・本人の同意取得はあなたにお願いします。こちらから誰にも連絡していません。できればPython学習数週間〜1年程度の人を集め、知人だけの場合はその偏りを記録します。

使うURL：https://error-learning-assistant.streamlit.app/

1. 下の質問で最近の実体験を聞く。
2. [提供タスクと進行用の答え](TASKS.md)で、操作・考えていることを観察する。
3. [空の匿名記録表](research_records.csv)に事実を記入する。氏名・学籍番号・成績・連絡先・本人のコードは記録しない。
4. 人数、途中終了、援助した回数、迷った場所、本人の説明を匿名で共有してください。発言引用を使う場合は、別途その原文の掲載許可を得てください。

現時点のAIは実APIの接続・品質が未検証です。通常の標準ガイドだけでテストできます。AI有効時のテストを行う場合は、運営設定と送信内容への同意を先に確認してください。

## 最初に伝えること

「アプリを試しています。あなたの能力を採点するものではありません。分からないところもそのまま教えてください。参加は自由で、いつでもやめられます。約20分、こちらで用意したコードを使い、氏名や成績は記録しません。匿名の操作結果とメモをハッカソン発表の集計に使います。録音・画面録画は行いません。原文の発言引用は別途確認します。」

実施前に、メモの削除日と、参加IDで撤回できる期限をあなたが決めて伝えてください。守れる日付を決めるまで記録を始めないでください。AIを使う場合は、画面の限定情報がOpenAIへ送られる点と、AIなしでも参加できる点を伝え、送信直前のアプリの同意も本人に確認してもらいます。

## 20分の進め方

| 時間 | 内容 |
|---|---|
| 0〜2分 | 同意、Python経験、参加IDの確認 |
| 2〜5分 | 最近エラーで止まった実体験を聞く |
| 5〜11分 | タスクAまたはBを使って操作。途中で答えを教えない |
| 11〜15分 | 別タスクをアプリなしで読み、即時の理解を確認 |
| 15〜20分 | 迷った点・次の行動を聞く。引用許可は個別に確認 |

参加順でA→B、B→Aを交互にします。順序を変えても小標本の前後比較は因果的な学習効果の証明にはなりません。進行役が操作を教えた場合は援助として数えます。

## 誘導しない質問

- 最近エラーで止まったとき、最初に何をしましたか？
- そのとき何が分からず、何を調べましたか？
- この画面で、次に何をしようと思いますか？
- 今の表示を自分の言葉で説明できますか？
- このあとコードの何を、どう確認しますか？
- 想像していた動きと違ったところはありましたか？
- 使わなかった表示や、意味を取りにくかった言葉はありましたか？

「ヒントは役立ちましたか」「AIで学べましたか」のように期待する答えを示す聞き方は避けます。

## 記録と判定

「場所を特定」「注目すべき名前・操作を特定」「具体的で妥当な次の確認行動を説明」をそれぞれ0/1で記録します。「コードを見直す」だけでは次の行動の得点にしません。観察できなければ空欄にし、0と区別します。模範回答はTASKS.mdにあります。

記録表は、1行を1人・1タスクとして使用します。保存したコードのコミット、表示モード、標準ガイド/AI選択/使用なしの区別、AI失敗、途中終了も記録します。列の空欄は未観測、yes/noは観測した事実です。

提出前の改修判断の目安：同じ箇所で2人以上止まったら修正候補。根拠と矛盾する質問や修正例の意図しない先出しは1件でも修正対象。集計は「成功人数/観測人数」で示し、参加・完了・中断・AI使用の母数を分けます。少人数の探索調査として報告し、全学生への効果やAIの優位性を主張しません。
