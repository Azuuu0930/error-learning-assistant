# 任意のAI選択機能：運営者の設定

現在の基本解析と標準ガイドはAPIキーなしで使えます。**AI選択は初期状態で無効、実APIでの動作・選択品質は未検証**です。接続済みであるかのようなデモや学習効果の主張はしません。

## 有効化に必要なもの

APIキーをチャットやGitHubに貼らないでください。Streamlit Community Cloudの管理画面 → Settings → Secretsに、次を設定します。ローカルではgitignore対象の `.streamlit/secrets.toml` を使えます。

```toml
AI_TUTOR_ENABLED = true
OPENAI_API_KEY = "ここだけに本物のキーを設定"
AI_TUTOR_ACCESS_CODE = "16文字以上の推測されにくい試用コード"
```

`.streamlit/secrets.toml.example` は無効な初期値の例です。APIキーと試用コードは別々にし、試用コードだけを協力者へ案内します。利用者がAPIキーを入力する欄はありません。設定変更後はアプリをRebootして、キャッシュされたサービスを作り直してください。

送信先は `https://api.openai.com/v1/responses` に固定。モデルは `gpt-5.4-mini-2026-03-17`、reasoning effort none、最大出力256トークン、store=false。モデルは[公式仕様](https://developers.openai.com/api/docs/models/gpt-5.4-mini)で確認していますが、アカウントの利用資格・請求状況・実際のパラメータ受理は実接続で確認が必要です。

## 実接続の確認（未実施）

1. 運営者がAPIプロジェクトの課金・利用制限と、試行に使う予算を確認する。
2. サンプルを解析しヒント3まで開く。「次の一歩を考える」で学習目的を選ぶ。
3. 送信先とJSON本文を確認。元コード、ログ本文、名前、値が含まれないことを確かめる。
4. 試用コードを入力し、本人が送信に同意したうえでボタンを1回押す。
5. AIが選んだ問い・根拠が表示され、モデルの返した自由文が表示されないことを確認する。失敗時は標準ガイドに戻る。
6. 成功・失敗、モデル、遅延、利用トークン/課金画面、根拠との整合を記録する。APIキー・試用コードは記録しない。

この確認が終わるまでは、AIの実動作成功・選択精度・費用の実測を主張できません。基本診断の42ケース評価は、このAIの品質評価ではありません。

## 費用と運用上限

1回の明示操作につき1リクエスト、再試行なし、ソケットのタイムアウト10秒、レスポンス64KiBまで。3回/セッション、30回/プロセスの24時間窓、同時処理1件。失敗も回数に数えます。セッションIDは入力を変えても保持します。

これらはメモリ上の試用制限で、プロセス再起動でリセットされます。複数プロセス間では共有されず、永続的な課金上限ではありません。公開環境での有効化には、試用コードの管理・ローテーション、APIプロジェクトの支出状況・制限を確認してください。試用コードが流出した場合は直ちに無効化または変更します。

公式表示の価格は入力$0.75、出力$4.50/100万トークン（2026-10-28確認）。費用の目安は `(入力トークン×0.75 + 出力トークン×4.50)/1,000,000 USD`。課金は未測定で、単価変更・アカウント条件は[公式モデルページ](https://developers.openai.com/api/docs/models/gpt-5.4-mini)で再確認してください。

## プライバシー

ログとコードは通常解析のためアプリサーバーに届きます。AI選択では、許可リストにある種類・行番号・信頼度・学習目的・既定の質問候補のみを送信します。元のメッセージ、ファイルパス、識別子、リテラル、comments、free-form detailsは渡しません。試用コードはアプリで照合し、OpenAIには送りません。APIキーは認証ヘッダーで送信します。

AI応答とプロバイダエラーの永続履歴は追加しません。別機能の[非公開エラー履歴](ERROR_HISTORY_SETUP.md)が有効な場合は、解析ボタンで送信されたエラー文を伏せ字処理してSupabaseへ保存します。これはOpenAIへの送信とは別です。現在のセッションには入力と結果を保持します。OpenAIにはstore=falseで要求しますが、これは提供元の保持がゼロという保証ではありません。[データ方針](https://developers.openai.com/api/docs/guides/your-data)と各提供元の方針も適用されます。
