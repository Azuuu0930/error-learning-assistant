# 学生・先生の使い方

## 学生

1. 上の「学生」を選び、Python・C・C++の対象言語を選ぶ。
2. エラー出力と必要なコードを貼り付けて解析。ヒントを一つずつ確認する。
3. 先生へ相談したい場合だけ「先生に相談する」を開き、今の状態と分かる範囲の実行環境を選ぶ。
4. 「保存する内容を確認」で中身を読み、「相談カードを保存」でJSONをダウンロードする。
5. 授業の案内に従ってファイルを先生へ渡す。自動では提出されない。

コード・ログ本文・変数名・ファイル名・氏名・自由記述はカードに含まれないため、このカードだけでコードの修正箇所を先生へ完全に伝えることはできません。コードの別共有は授業の方針に従ってください。
同じ解析を状態変更後に保存し直した場合は、最新版だけを先生へ渡します。

## 先生

1. 上の「先生」を選ぶ。これは画面切替で、教員認証ではない。
2. 学生が任意に渡したJSONファイルを選び、「カードを読み込む」を押す。
3. 言語とコンパイル・リンク・実行の段階で絞り、復習候補とエラーの種類・診断コードを別々に確認する。
4. 必要なら表示中の集計をCSVで保存する。
5. 「読み込んだカードを消去」でこの画面の読込結果を消す。

## 集計の読み方と限界

- **相談件数であり、人数ではありません。** 同じ学生の別相談も含み、人物の重複を除く仕組みはありません。
- 「解決した」は自己申告で、修正後の実行をアプリが確認したものではありません。
- 学習概念はログ分類からの候補です。理解不足、成績、教員の対応の良否を判定するものではありません。
- 複数候補を持つ相談があり、候補件数の合計が相談件数を超える場合があります。
- ヒントモードの修正例閲覧は操作状態を記録。通常モードの修正例の開閉は測定できず「未計測」です。
- カードは編集可能なファイルであり、本人や実行結果を認証した記録ではありません。
- 同じID・同じ内容は一件だけにし、同じIDで内容が異なる場合はそのIDをすべて集計から除外します。最新版だけを選び直してください。
- 1枚16KiB、最大100ファイル・合計1MiB。JSON以外・余分な項目・未知の版・矛盾する内容は取り込みません。
- 入力カードはアプリサーバーに届き、このセッション内で集計します。カードの永続保存・自動共有・外部AI送信は行いません。エラー入力画面には別機能の[非公開エラー履歴](ERROR_HISTORY_SETUP.md)があり、有効時のエラー文は運営者だけが管理画面で確認できます。先生のカード集計からは閲覧できません。ホスティング先の方針も適用されます。
- ダウンロードしたファイルと実施メモの保管・共有・削除は、先生と参加者が合意した手順で行ってください。
- 対象授業・コンパイラ・IDEの実ログ、実学生による使いやすさ、学習効果、先生による集計活用は未検証です。[現地調査依頼](RESEARCH_REQUEST.md)に従って小さく試します。

PythonはASTによるコード補助解析がありますが、C/C++はコンパイラ等のログ解析です。C/C++に同じコード解析能力があるとは扱いません。任意AIの追加ガイドは現在Pythonのみです。
